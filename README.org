* make-container
Make Linux Container Image based on various gnu/linux distributions

** Domain
This image is created for running make targets in container
environments.

Currently supported GNU/Linux distributions are:
- fedora
- debian
- alpine

** Engineering

*** Prerequisites
- podman
- docker

*** Building the container image
#+begin_src bash
  BUILDER=docker make all
#+end_src

*** Pushing the image to docker container repository
#+begin_src bash
  BUILDER=docker make install
#+end_src

*** Incrementing the versions
#+begin_src bash
  make increment-fedora-version
  make increment-debian-version
  make increment-alpine-version
#+end_src
